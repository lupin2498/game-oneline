# Đường Kẻ Một Nét (One Line)

Game HTML5 canvas, một file duy nhất (`index.html`), chạy offline, hỗ trợ chuột và cảm ứng.

**Luật:** giữ ngón tay vào vòng sáng rồi kéo, vẽ một đường liền qua mê cung đang cuộn.
Nhấc tay hoặc chạm tường là thua.

**Độ khó tăng dần:** hành lang hẹp dần (±54px → ±12px), thỉnh thoảng có cửa thắt,
biên độ bẻ ngoặt và tốc độ cuộn tăng theo quãng đường (130 → 440 px/s).

Kỷ lục lưu bằng `localStorage`.
